# Contributing to cloud-itonami-isco-3117

Thank you for your interest in contributing to this project. We welcome contributions from the community.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a new branch for your work.
3. Install dependencies: `kbb -M:deps`
4. Run tests: `kbb -M:test`

## Contribution Process

1. Make your changes in your branch.
2. Ensure all tests pass locally before pushing.
3. Push to your fork and create a pull request.
4. We'll review your changes and provide feedback.

## Code Standards

- All source code in `.cljc` for portability (JVM/browser/WASM compatibility).
- Follow Clojure style conventions (2-space indent, kebab-case).
- All new features must include tests.
- Commit messages should be clear and descriptive.

## Reporting Issues

Please use the GitHub Issues tab to report bugs or suggest enhancements. Include as much detail as possible about the issue.
